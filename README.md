# Tidrapport

Enkel installerbar webbapp (PWA) för tidrapportering. All data sparas lokalt i webbläsaren – ingen server, ingen inloggning.

Källkod ligger i `app/`. Ikoner och typsnitt ligger base64-kodade och avkodas av GitHub Actions som publicerar till grenen `gh-pages`.

Typsnitt: Yellowtail (Apache License 2.0).
